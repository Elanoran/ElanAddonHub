one click installs or updates them, with a checksum check on every download and a backup to roll back to.

If you'd rather not run the Outpost, every addon can be downloaded on its own and installed by hand. The links below

## Installing by hand

1. Download the zip (and the ones it needs, see *Needs*).
2. Unzip it into `World of Warcraft\_forever_\Interface\AddOns\`. Each zip holds one folder with the addon's name, for
   example `ElansBags`. Keep that name: `ElansBags-main` or `ElansBags (1)` will not load.
3. Quit WoW completely and start it again. A `/reload` does not pick up a new addon.

**Updating:** download the zip again, delete the old folder and unzip the new one in its place. Your settings are kept:
they live in WoW's `WTF` folder, not in the addon folder.

Installed by hand, nothing updates by itself and nothing checks the download for you. That is what the Outpost adds.
