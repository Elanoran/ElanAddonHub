1.0.0 First version: shares your character, class, level and zone with the Lodge

1.1.0 Adds the /rl shortcut for /reload (moved here from Elan's Hunter Helper)

1.2.0 Also shares race and gender (for avatars) and whether you are still logged in, so the hub stops showing the wrong character after you log out or switch

1.3.0 Adds a tiny status strip in the top-left screen corner (32 coloured squares, 4 pixels each) so the Hub sees your character instantly, without /reload. Turn it off with /ehub pixel off.


1.4.0 Adds a minimap button, a settings window (/ehub) and a quick emote wheel: hover or click the small icon for 8 emotes (Thank, Cheer, Wave, Hello, Bow, Laugh, Applaud, Dance by default, configurable). /ehub diag records emote API facts.

1.5.0 Richer presence for the Hub: the status strip gets a second row with your zone, XP %, rested state, group size, instance and a few flags (in combat, dead, AFK, resting). It never reads health, power, buffs or cooldowns. Older Hubs ignore the extra row. Updates on zone, combat, group and XP events, throttled to twice a second.

1.6.0 Optional "Emotes" chat tab so /e emotes and text emotes (/dance, /thank, the emote wheel) no longer fill General. On by default, per character, out of combat only. Switch in /ehub settings or with /ehub emotes on|off; turning it off restores General exactly.

1.7.0 New settings window with a tab list on the left (General, Emote wheel, About) like Elan's Hunter Helper; /ehub wheel opens the Emote wheel page and the window remembers the last page. Removed the Emotes chat tab - emotes are back in General (a one-time cleanup puts them back where 1.6.0 took them from, and closes the tab if the Hub made it).

1.8.0 Addon health for Elan's Outpost: errors of this addon are kept in the saved variables (ElansHubDB.bugs), and on the first login after an update one quiet /ehub diag run is stored (about 10 s after login, out of combat) with a one-time chat hint to /reload so the Outpost can check it.

1.9.0 Saves the in-game calendar for Elan's Outpost: holidays and world events (Darkmoon Faire, Hallow's End...), raid reset times and your own calendar / guild events, so the Lodge calendar can show them. Pure API reads, out of combat, once after login and then at most once an hour; nothing is sent anywhere by the addon. /ehub calendar shows the state (refresh | on | off), /ehub diag records whether the client has the calendar API. Turn it off with /ehub calendar off. Also: hovering the status strip in the top-left corner now explains what it is (the tooltip opens below it so the Outpost can still read it; clicks pass through).

1.9.1 Fixes the in-game calendar merging repeating holidays into one month-long span: Call to Arms weekends or a fishing contest every Sunday are now saved as separate occurrences (the game's START / ONGOING / END day marks are used, and an occurrence joins only consecutive days). The Outpost's calendar can now tell them apart. /reload to update the saved calendar.

1.9.2 New /ehub copy: shows your recent chat lines as plain text in a box you can copy from (Ctrl+A, Ctrl+C) - handy for /run output. New /ehub talentapi: lists which talent functions this WoW client has (saved for Elan's Outpost too).

1.9.3 New /ehub talentprobe: walks this client's talent trees (read-only) and shows/saves what it finds, so Elan's Hunter Helper can read your talents on WoW Forever.

1.10.0 New file SharedData.lua: Elan's Outpost writes the lodge's shared flight-path times into it, for Elan's Hunter Helper to read (an ElansHubShared table; empty until the Outpost fills it). The addon file list changed, so a ONE-TIME full WoW restart is needed after this update (a /reload does not pick up a new file in the .toc).

1.11.0 New data layer for Elan's Outpost: a public ElansHub.Publish / Get / CharKey API (Data.lua, new SavedVariable ElansHubData) that other Elan addons will hand their data to, stored versioned per character. The Hub itself now also saves your character basics (name, class, level, XP, rested XP, money, guild, zone) there. Pure API reads, out of combat; nothing is sent anywhere by the addon. The addon file list and SavedVariables changed, so a ONE-TIME full WoW restart is needed after this update (a /reload does not pick up a new file in the .toc).

1.12.0 The Hub now collects your bags, bank, guild bank, equipped gear, talents and professions for Elan's Outpost (new file Collect.lua), handed to the data layer as versioned modules. Event driven, never in combat, each scan throttled (bags/bank/gear/talents/professions at most every 2 s, guild bank every second); the bank and guild bank are read only while you have them open, and the guild bank merges into what it saved before so other guilds and tabs you did not look at are kept. Pure API reads, nothing is sent anywhere by the addon. New /ehub data prints, per module, its version, age and item count so you can check it worked. The addon file list changed, so a ONE-TIME full WoW restart is needed after this update (a /reload does not pick up a new file in the .toc). New ElansHub.Subscribe(module, fn) lets other Elan addons refresh when the Hub has stored new data (errors in their callback never reach the Hub). Talent nodes now also carry their spell icon (ic) so the Outpost can draw the real talent icons.
